# Codex Account Switcher v1.0.1

## Русский

Первый публичный релиз Codex Account Switcher.

Программа помогает безопасно переключаться между несколькими аккаунтами Codex/OpenAI на одном Windows-компьютере. Она меняет только `auth.json`, оставляя общими проекты, чаты, MCP, плагины, skills и инструменты.

### Скачать

- `CodexAccountSwitcherSetup-win-x64.msi` — установщик для Windows 10/11 x64.
- `CodexAccountSwitcherSetup-win-x86.msi` — установщик для Windows 10/11 x86.
- `CodexAccountSwitcher-portable-win-x64.zip` — portable x64.
- `CodexAccountSwitcher-portable-win-x86.zip` — portable x86.

### Важно

Не выходите из Codex обычной кнопкой logout при записи нескольких аккаунтов. Такой выход может отозвать refresh token.

## English

First public release of Codex Account Switcher.

The app helps safely switch between several Codex/OpenAI accounts on one Windows computer. It changes only `auth.json` and keeps projects, chats, MCP, plugins, skills, and tools shared.

### Downloads

- `CodexAccountSwitcherSetup-win-x64.msi` — installer for Windows 10/11 x64.
- `CodexAccountSwitcherSetup-win-x86.msi` — installer for Windows 10/11 x86.
- `CodexAccountSwitcher-portable-win-x64.zip` — portable x64.
- `CodexAccountSwitcher-portable-win-x86.zip` — portable x86.

### Important

Do not use the normal Codex logout button when recording multiple accounts. Logout can revoke the refresh token.
