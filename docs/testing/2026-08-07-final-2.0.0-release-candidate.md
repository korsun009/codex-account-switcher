# Codex Account Switcher 2.0.0 final release verification

Date: 2026-08-07 (Europe/Moscow)

## Result

The stable `2.0.0` source and complete Windows release matrix passed the functional, updater, packaging, and secret gates. The release can be published with an explicit unsigned-binary warning.

No trusted Code Signing certificate with a private key is available on this Windows user/machine. Every installer and executable reports `NotSigned`. The production script still rejects unsigned output by default; this candidate was created with the explicit `-AllowUnsigned` override. No self-signed certificate is represented as publisher identity.

- Combined x64/x86 NSIS installer used by `latest.yml`.
- Architecture-specific x64 and ia32 NSIS installers.
- x64 and ia32 MSI installers.
- x64 and ia32 portable ZIP files.
- Three NSIS blockmaps, `latest.yml`, and `SHA256SUMS.txt`.
- Self-contained .NET backends published as `win-x64` and `win-x86` and mapped to the matching Electron resources.
