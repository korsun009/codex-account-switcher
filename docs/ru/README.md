# Codex Account Switcher

## Что это

Codex Account Switcher — локальная Windows-программа для безопасного переключения между несколькими аккаунтами Codex/OpenAI на одном компьютере. Она сделана для людей, которые работают с несколькими профилями Codex и не хотят каждый раз вручную выходить, входить, терять refresh token или ломать уже сохранённые входы.

Программа оставляет общими проекты, чаты, MCP, плагины, skills и настройки инструментов. Меняется только активный вход в Codex.

Подходит, если у вас есть:

- рабочий и личный аккаунт;
- отдельные аккаунты под разные задачи;
- тестовый аккаунт для проверки поведения Codex;
- несколько профилей, между которыми нужно переключаться без повторной настройки всей среды.

## Какую проблему решает

Codex хранит текущий вход в файле `auth.json`. Если выйти из Codex обычной кнопкой logout, refresh token может быть отозван. После этого сохранённый вход может перестать работать, и аккаунт придётся добавлять заново.

Codex Account Switcher не делает обычный выход из аккаунта. Вместо этого он сохраняет локальные снимки входа для каждого профиля и переключает только `auth.json`. Всё остальное в `.codex` остаётся общим.

Такой подход удобен, когда нужно быстро перейти между аккаунтами, но при этом сохранить один общий рабочий контекст Codex.

## Как скачать

Скачивайте последнюю версию в [GitHub Releases](https://github.com/korsun009/codex-account-switcher/releases/latest). Там есть четыре основных файла:

| Система | Установщик | Portable |
| --- | --- | --- |
| Windows 10/11 x64 | `CodexAccountSwitcherSetup-win-x64.msi` | `CodexAccountSwitcher-portable-win-x64.zip` |
| Windows 10/11 x86 | `CodexAccountSwitcherSetup-win-x86.msi` | `CodexAccountSwitcher-portable-win-x86.zip` |

Windows 8/8.1 не поддерживаются. .NET отдельно ставить не нужно.

## Что умеет программа

- Автоматически ищет папку `.codex` при первом запуске.
- Если папка не найдена, просит выбрать её вручную.
- Позволяет добавлять новые профили прямо из интерфейса.
- Ведёт пользователя по шагам: создать профиль, открыть Codex, войти вручную, сохранить вход.
- Переключает активный профиль одной кнопкой.
- Показывает текущий активный аккаунт.
- Показывает лимиты Codex для всех сохранённых профилей.
- Хранит список профилей в локальной SQLite-базе.
- Делает резервную копию перед заменой текущего входа.
- Поддерживает русскую, английскую и китайскую локализацию.
- Имеет темы: автоматически, тёмная, серая, светлая.
- В автоматическом режиме подстраивается под тему Windows.

## Чего программа не делает

- Не отправляет токены и данные аккаунтов на сервер.
- Не записывает содержимое `auth.json` в SQLite-базу.
- Не разделяет проекты, чаты, MCP, плагины, skills и инструменты по аккаунтам.
- Не обходит лимиты OpenAI или Codex.
- Не меняет подписку, права доступа или ограничения аккаунта.
- Не поддерживает Windows 8/8.1.

## Как пользоваться

1. Установите MSI или распакуйте portable zip.
2. Запустите программу.
3. При первом запуске программа найдёт папку `.codex`. Если не найдёт, выберите её вручную.
4. Нажмите `Добавить аккаунт`.
5. Введите понятное имя профиля.
6. Нажмите `Открыть Codex`, войдите в нужный аккаунт вручную.
7. Вернитесь в программу и нажмите `Сохранить вход`.
8. Для переключения нажимайте `Перейти` на нужной карточке профиля.

## Добавление нового аккаунта

Добавление аккаунта сделано как мастер внутри программы. Пользователь контролирует процесс, но не должен помнить порядок кнопок.

1. Откройте `Добавить аккаунт`.
2. Введите название профиля, например `рабочий Codex` или `личный`.
3. Нажмите `Создать профиль`.
4. Нажмите `Открыть Codex`.
5. В Codex вручную войдите в нужный аккаунт.
6. Вернитесь в программу.
7. Нажмите `Сохранить вход`.

После этого профиль появится в списке и будет доступен для переключения.

## Безопасность

- Переключается только `auth.json`.
- Проекты, чаты, MCP, плагины и инструменты остаются общими.
- Содержимое `auth.json` не записывается в SQLite-базу.
- Перед заменой входа создаётся резервная копия.
- Токены не выводятся в интерфейс и журнал.

Важно: не используйте обычный logout в Codex при записи нескольких аккаунтов. Такой выход может отозвать refresh token и сломать сохранённый вход.

## Лимиты Codex

Экран `Лимиты Codex` показывает 5-часовой и недельный лимит для всех сохранённых профилей. Для проверки программа читает только нужные значения из локального `auth.json` каждого профиля, делает запрос к usage endpoint и не сохраняет токены в базе.

Эта функция только показывает информацию. Она не увеличивает лимиты и не пытается их обходить.

## Установщик и portable

Есть два варианта использования:

- MSI-установщик — обычная установка в Windows с удалением через системные настройки или uninstall-файл.
- Portable zip — распаковали папку и запустили программу без установки.

Для каждого варианта публикуются x64 и x86 сборки. Все пользовательские изменения должны проверяться для всех четырёх вариантов.

## Сборка из исходников

Нужны Windows 10/11, .NET 8 SDK и поддержка WiX Toolset для проектов установщика.

```powershell
dotnet test codex-account-switcher\CodexAccountSwitcher.sln
.\scripts\build-release.ps1 -Version v1.0.1
```

Скрипт создаёт portable x64, portable x86, MSI x64, MSI x86, архив исходного кода и файл `SHA256SUMS.txt`.
