# 2.3.1 — исправление сохранения активных чатов

Исправлено прерывание переключения с сообщением «Не удалось сохранить активные чаты» при включённом продолжении задач после переключения аккаунта.

Switcher больше не передаёт пустой `cursor` при запросе первой страницы чатов: текущий Codex отклонял такой запрос. Следующие страницы по-прежнему читаются с возвращённым курсором. Сохранение непрочитанности, ошибок и ожиданий, шифрование снимка и остановка переключения при реальной ошибке сохранения сохранены.

Проверено на установленном Codex 26.1111.2228.0: полный сбор состояния и чтение зашифрованного снимка прошли без переключения аккаунта. Выпуск включает x64/x86 portable, MSI и установщики для автообновления.

Как и предыдущий выпуск, пакеты пока без подписи Authenticode. Для проверки целостности приложен SHA256SUMS.txt.

Формат профилей и снимков не изменён. Для отката можно установить предыдущий выпуск 2.3.0 без миграции данных.
