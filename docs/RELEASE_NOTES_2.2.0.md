# Codex Account Switcher 2.2.0

При переключении профиля Switcher переносит отметки непрочитанности локальных чатов. Прочитанные чаты не становятся непрочитанными снова. Поддерживаются прежние атомы renderer и новое хранилище `electron-thread-read-state-v1`; состояния удалённых хостов не переносятся.

В настройках добавлен выключенный по умолчанию тумблер **«Продолжать активные чаты после переключения»**. При включении Switcher сохраняет список активных локальных чатов до закрытия Codex и отправляет каждому подходящему чату команду продолжить после успешного запуска нового аккаунта. Команда видна в истории чата. Настройки модели и разрешения сохраняет сам Codex.

Продолжение пропускается, если чат уже работает, завершился, получил новый запуск либо ожидает ответа или разрешения пользователя. Перед отправкой проверяется идентификатор последнего запуска. Попытка записывается на диск до отправки: при потере ответа автоматической повторной отправки нет. Результат требует ручной проверки в чате. Внешнее одновременное управление чатом между проверкой и отправкой полностью исключить нельзя: у локального инструмента нет условной атомарной отправки.

Ошибки, ожидания и непрочитанные результаты сохраняются в зашифрованном Windows DPAPI снимке и доступны в настройках Switcher. Нативные красные значки старых ошибок в Codex не восстанавливаются: поддерживаемого механизма для них не найдено. Это снимок на момент переключения, а не постоянно обновляемый монитор.

На старых версиях Codex без локального App Tools переключение с выключенным продолжением сохраняется; приложение сообщает о недоступности снимка. С включённым продолжением неполный снимок останавливает операцию до закрытия Codex. Если Codex уже закрыт, переключение выполняется без попытки продолжать старые задачи. Сбой продолжения после смены аккаунта не откатывает вход под работающими задачами.

Дистрибутивы: x64 и x86 portable, NSIS и MSI. Установщики без Authenticode-подписи; контрольные суммы прилагаются.
