# Canva Icon Brief — Codex Account Switcher

Create a Windows app icon for a safe local Codex account switcher.

Visual direction:

- Simple symbol, readable at 32 px.
- Three small user/account dots or cards orbiting one shared secure folder.
- Include a subtle shield or lock cue, but avoid aggressive cybersecurity styling.
- Palette should match the app: blue `#2563EB`, teal `#0F766E`, amber `#B45309`, near-black `#171F2B`, white.
- Style: clean vector, soft corners, professional utility app.

Avoid:

- Keys, password fields, visible tokens, terminal code blocks.
- Bright neon gradients.
- Visuals that imply cloud sync or copying all user data.

Suggested Canva generation prompt:

> Minimal Windows desktop app icon for "Codex Account Switcher": three account dots/cards around one shared secure local folder, subtle shield lock symbol, clean vector style, soft corners, professional utility design, blue teal amber charcoal white palette, readable at small size, no text, no passwords, no code.
