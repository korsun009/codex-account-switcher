# Переключатель аккаунтов Codex

Небольшая Windows-утилита для переключения активного OpenAI-аккаунта Codex при сохранении общей рабочей папки:

```text
%USERPROFILE%\.codex
```

Приложение специально сделано консервативным. Оно переключает только снимки file-backed `auth.json`; `config.toml`, проекты, сессии, archived sessions, плагины, skills, MCP-настройки, memories, rules и tools остаются общими.

## Готовые portable exe

```text
bin\Release\net8.0-windows\win-x64\publish\CodexAccountSwitcher.exe
bin\Release\net8.0-windows\win-x86\publish\CodexAccountSwitcher.exe
```

## Установщик Windows

MSI собирается через WiX Toolset 6. Есть отдельные установщики для 64-битных и 32-битных Windows 10/11:

```powershell
dotnet restore .\CodexAccountSwitcher.sln
dotnet build .\Installer\CodexAccountSwitcher.Installer.wixproj -c Release
dotnet build .\InstallerX86\CodexAccountSwitcher.InstallerX86.wixproj -c Release
```

Готовые установщики:

```text
Installer\bin\Release\CodexAccountSwitcherSetup.msi
InstallerX86\bin\Release\CodexAccountSwitcherSetup-x86.msi
```

Windows 8/8.1 не являются целевой платформой. Для них отдельная legacy-ветка не поддерживается.

Установщик показывает обычный мастер установки WiX: можно выбрать папку установки и отключить дополнительный ярлык на рабочем столе через выбор компонентов. Ярлык в меню Start создаётся для запуска программы. Удаление выполняется стандартно через Windows: `Приложения` -> `Установленные приложения` -> `Codex Account Switcher` -> `Удалить`. Локальные профили, база настроек и `auth.json` в установщик не попадают.

Иконка приложения берётся из `Assets\AppIcon.ico` и используется в portable exe, окнах программы, ярлыках установщика и списке установленных программ Windows.

## Первый запуск

1. Откройте приложение.
2. Приложение автоматически найдёт папку `.codex`. Если не найдёт, выберите её вручную.
3. Откройте меню `Сервис` -> `Инвентаризация файлов`, чтобы записать несекретный отчёт в выбранную папку `.codex\_account_profiles`.
4. В меню `Сервис` можно вручную создать бэкап входа перед любыми действиями с аккаунтами.
5. Если нужно, откройте `Сервис` -> `Настроить хранение auth.json`. Это добавит `cli_auth_credentials_store = "file"` в начало `config.toml` и создаст `config.toml.account-switcher.bak`.
6. Для нового аккаунта нажмите `Добавить аккаунт`.
7. Введите понятное название профиля и нажмите `Создать профиль`.
8. Нажмите `Открыть Codex`, войдите в нужный аккаунт **без нажатия обычного "Выйти"** в Codex.
9. Вернитесь в мастер и нажмите `Сохранить вход`.

После того как у всех профилей появился `auth.json`, используйте кнопки `Перейти` на нужной карточке.

## Мастер добавления аккаунта

Кнопка `Добавить аккаунт` открывает отдельный пошаговый мастер:

1. `Создать профиль` — добавляет профиль в базу приложения. На этом шаге вход Codex ещё не меняется.
2. `Открыть Codex` — делает бэкап, временно убирает текущий вход и открывает Codex для ручного входа.
3. `Сохранить вход` — сохраняет новый вход в созданный профиль после того, как вход в Codex уже завершён.

Мастер не входит в аккаунт сам. Пользователь контролирует момент входа и момент сохранения. Если нажать `Сохранить вход` до завершения входа в Codex, программа покажет сообщение, что текущий вход не найден.

## Настройки

Меню `Меню` -> `Настройки` открывает боковую панель. В ней можно:

- выбрать тему: `Автоматически`, `Темная тема`, `Серая тема`, `Светлая тема`;
- выбрать язык интерфейса: русский, English, 中文;
- добавить новый профиль Codex;
- удалить неактивный профиль Codex.

Список профилей, выбранная папка Codex Home и настройки темы хранятся в локальной SQLite-базе:

```text
%APPDATA%\CodexAccountSwitcher\switcher.db
```

Язык сохраняется в той же базе. При смене языка приложение перезапускается, чтобы меню, настройки, инструкции и диалоги открылись уже на выбранном языке.

Сами входы по-прежнему лежат только в профильных `auth.json` внутри выбранной `.codex\_account_profiles` и не выводятся в интерфейс. Если рядом уже есть старый `profiles.json`, приложение подхватит его как миграционный источник.

## Лимиты Codex

Меню `Меню` -> `Лимиты Codex` открывает отдельный экран внутри приложения. Он проверяет все профили, которые есть в базе, и показывает:

- остаток 5-часового лимита;
- остаток недельного лимита;
- ближайшее время сброса, если оно есть в ответе.

Для активного профиля используется текущий live `auth.json`, для остальных — сохранённый `auth.json` в папке профиля. Приложение читает только `access_token` и `account_id`, делает запрос к ChatGPT usage endpoint и сразу забывает эти значения. Токены не выводятся, не пишутся в журнал и не сохраняются в SQLite.

## Безопасность

- Переключение закрывает все процессы `Codex.exe` и `codex.exe` перед заменой входа.
- Содержимое токенов никогда не выводится.
- Если у целевого профиля нет `auth.json`, переключение отклоняется.
- Каждое переключение создаёт pre-switch backup в `.codex\_account_switcher_backups`.
- `Откатить последнее` восстанавливает самый свежий сохранённый `auth.json`.
- Для записи нескольких аккаунтов используйте `Добавить аккаунт`, а не обычный logout в Codex. Обычный logout может отозвать refresh token и сделать сохранённый профиль недействительным.
- Удаление активного профиля запрещено. Сначала переключитесь на другой профиль.

## Текущее ограничение

Хранилище OAuth сторонних коннекторов ещё не доказано. Сейчас приложение переключает только OpenAI `auth.json`. Добавлять credential-файлы коннекторов можно только после before/after-инвентаризации, если она докажет, что файл относится именно к аккаунту, а не к общим проектам, чатам или плагинам.
